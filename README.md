# 💬 SentimentIQ — AI-Based Sentiment Analysis Tool

> A web-based sentiment analysis system that classifies text as **Positive**, **Negative**, or **Neutral** using NLP — achieving 85%+ accuracy on 10,000+ records.

## ✨ Features
- 🧠 AI Sentiment Classification — Positive, Negative, Neutral using NLTK VADER
- 📊 Interactive Dashboard — Real-time sentiment visualization with charts
- 📁 Bulk Processing — Handles CSV and text inputs (10,000+ records)
- ⚡ 60% reduction in manual sentiment analysis effort
- 🌙 Dark/Light Mode toggle
- 🔐 User Authentication — Sign in / Sign up
